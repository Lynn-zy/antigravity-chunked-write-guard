# 分段写入规范（Chunked Write Guard）

<!-- 当前档位：500 行 · 标准档（可在 Write Guard 侧边栏面板切换 700 / 500 / 300 档） -->

为避免单次输出过长导致流式超时（`The stream was interrupted`）和零进度重试，写入或修改文件时遵守以下限制：

1. **单次写入目标 ≤ 500 行**：每次 `write_file`（含 `Append: true`）或 `edit_file` 的新内容控制在 500 行以内。
2. **长文件分步写入**：预计超过 500 行的文件（如单页 HTML 原型、大型组件、长文档或脚本），拆成多步完成。
   - 第 1 步用 `write_file` 写入骨架与核心结构（≤ 500 行）。
   - 后续按模块分次调用 `write_file(Append: true)` 或 `edit_file` 补齐，让每段改动尽快落盘。
3. **拦截上限与断流恢复**：
   - 本地 `PreToolUse` Hook 的单次写入上限为 **800 行**或 **48 KB**，`edit_file` 合计上限为 900 行或 56 KB。被拦截后拆成更小分段继续写，不要原样重试。
   - 收到断流恢复提示时，本轮单次写入控制在 **≤ 300 行**以内，确保先成功落盘。
